Is that safe? What does the command do?

Never run a script you can't read - so read it first. It's a few dozen lines of plain text, and everything it installs is public: github.com/KollegDev/claudetldr. Read them right here: setup.bat · run-once.bat · uninstall.bat · serve-service.ps1 (the server itself).

What it does: downloads the viewer and a ~140-line PowerShell server into its own folder, then serves your conversations at 127.0.0.1:7817. What it does not do: no admin rights, no copies of your conversations, no outbound connection afterwards, no telemetry, no account - and the socket is bound to 127.0.0.1, unreachable from the network. The install command adds exactly one autostart entry; the portable one adds nothing. Remove everything with uninstall.bat.

About the Windows warning: it appears for every script downloaded from the internet, regardless of content - Windows tags browser downloads, and only a paid code-signing certificate silences it. That's why the file is kept short and readable: open it in Notepad, see the few lines it runs, then decide. Rather avoid the download entirely?
